Источник анализа: `platform/материал.zip`

## 1) Типы заданий (по фактическим примерам)

1. **Творческий плакат / слоган**
   - Примеры: "Психологическая реклама", "Житейская психология в рекламе".
   - Выход ученика: выбранная сфера/продукт, слоган, эскиз.

2. **Кейс-аналитика (ситуация -> решение)**
   - Пример: "Этический детектив".
   - Выход: какой принцип нарушен, как правильно действовать.

3. **Визуализация психологического состояния**
   - Пример: "Цвет и форма состояния".
   - Выход: рисунок + объяснение выбора цвета/формы.

4. **Применение научного метода к бытовой ситуации**
   - Пример: "Метод на службе жизни".
   - Выход: выбранная ситуация, метод, краткий план применения.

5. **Схема/символическое сравнение понятий**
   - Пример: "Одной картинкой" (житейская vs научная психология).
   - Выход: простой рисунок/схема.

6. **Классификация по описанию (определи метод)**
   - Пример: "Сыщик" (наблюдение vs эксперимент).
   - Выход: выбор метода + короткое обоснование.

7. **Проектирование мини-исследования**
   - Пример: "Мой идеальный метод".
   - Выход: выбранный метод + пошаговый план 2-3 пункта.

8. **Поиск и исправление ошибок в тексте**
   - Пример: "Ошибки в инструкции".
   - Выход: найденные ошибки + корректные формулировки.

9. **Эссе / рефлексия**
   - По перечню: "роль одного из методов в психологии", "роль психологии в современном мире".
   - Выход: связный текст по теме.

10. **Наблюдение в реальной жизни**
    - По перечню: определить темперамент человека и обосновать.
    - Выход: описание наблюдения + аргументация.

11. **Тестовые задания**
    - По перечню: тесты по темам + отдельный тест на темперамент.
    - Выход: ответы по закрытым/полуоткрытым вопросам.

## 2) Форматы ответа ученика (что должен уметь конструктор)

- `single_choice` - выбрать один вариант (метод/сфера/ситуация)
- `short_text` - короткий ответ/обоснование (1-3 предложения)
- `long_text` - эссе/развернутый ответ
- `structured_plan` - список шагов (2-3 пункта)
- `error_fix` - пара "ошибка -> исправление" (повторяемый блок)
- `drawing_upload` - рисунок/эскиз (файл) + текстовый комментарий
- `classification` - разметка нескольких ситуаций по категориям
- `mixed` - комбинированный формат (например, выбор + текст + файл)

## 3) Наблюдаемая вариативность в постановке заданий

- **По уровню открытости**:
  - закрытые (классифицировать, выбрать метод),
  - полуоткрытые (выбор + объяснение),
  - открытые (эссе, творческий плакат).

- **По типу мыслительной операции**:
  - воспроизведение знаний,
  - применение знаний к ситуации,
  - анализ/диагностика ошибок,
  - синтез (создание нового продукта: плакат, схема, план),
  - рефлексия/аргументация.

- **По артефакту результата**:
  - текст,
  - схема/рисунок,
  - смешанный ответ (текст + визуальный объект).

- **По контексту**:
  - учебный (описанные кейсы),
  - жизненный (наблюдение в быту),
  - профессионально-этический (работа психолога).

## 5) Что важно учесть в UI конструктора педагога

1. **Шаблоны по типам задания** (быстрый старт).
2. **Комбинирование полей** (текст + выбор + файл).
3. **Повторяемые группы полей** (ошибка/исправление, ситуация/метод/почему).
4. **Отдельная поддержка творческих работ** (загрузка изображения и комментарий).
5. **Режим ручной проверки** как основной (большинство задач открытого типа).

- "Творческий плакат/эскиз + пояснение"  
- "Эссе"  
- "Наблюдение в реальной жизни (дневник/вывод)"
